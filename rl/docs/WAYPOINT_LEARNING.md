# 布点（关键点）网络：设计问题、训练方法、评估协议

> 本文档回答三件事：**训练布点网络会踩什么坑**、**有哪些可行训练方法**、**如何证明它"更有效"**（含"看回放数据"这条路线的三个陷阱）。

---

## 1. 设计上你会遇到的问题（四类）

### 1.1 标签问题（最根本）

1. **没有"正确答案"**。当 K < |V| 时，"最优子集"是组合优化（一般 NP-hard），不存在现成标签。可用的全是**代理**：暴力枚举（小图才行）、贪心边际增益、leave-one-out 重要性、使用频率。代理与真实目标（下游任务表现）之间**必然有偏差**。
2. **逐点重要性不可加**。同一堵墙的两个相邻角点贡献高度重叠（冗余），逐点打分取 top-K 会选出一堆互相冗余的点。**必须处理集合冗余**（多样性项、边际增益、子模优化）。
3. **标签依赖生成数据的策略**（见第 4 节，这是你"看回放"路线的主要风险）。

### 1.2 表示与输出问题

4. **输出是离散集合**，不是连续向量：top-K 不可微，"路径变差了该怪哪个点"的信用分配是组合爆炸的。要么用可微软 top-K，要么用监督绕开。
5. **K 本身是个超参**，而且最优 K 依赖下游（车宽、最小转弯半径、交通密度）。K 太小路径差，K 太大会退化成"全拿"（学习任务消失）。
6. **候选集决定上限**：候选里没有的好点，网络永远选不出来。候选粒度还直接决定计算量（几百 → 几万）。候选来源也是设计决定（粗网格 / 自由空间采样 / 中轴线）。
7. **可变长输入**：地图尺寸、障碍数量、连通性都在变 → 候选数量可变，必须 mask（**这才是本条线真正需要 mask 的地方**）。
8. **等变性**：地图镜像/旋转时，布点应当等变。不做数据增强的话网络会浪费容量学"左"和"右"两套东西。

### 1.3 连通性问题（**最容易忽略的致命坑**）

9. **top-K 逐点打分完全不管连通性**。选出来的 K 个点，如果建边后图断裂，就会出现"无解"的路径——**这是硬约束失效，不是精度问题**。
10. **边怎么建**：全连（会有穿墙边，必须过滤）还是可见性检查后连（可能不连通）。两种都要额外的几何查询与连通性修复（补点或改边）。
11. **必须显式检查连通性**：建图后跑一次连通分量检查，断裂就补点重连。这一步不做，评估时会出现莫名其妙的"到达失败"，而你会误以为是 RL 的问题。

### 1.4 工程一致性问题

12. **训练与评估必须用同一张图**。如果每次前向都重算布点，策略面对的是**分布漂移的图**（微小的输入变化 → 输出点集跳变 → 路径跳变），你辛苦建立的"同配置"纪律就废了。**建议：把网络生成的图导出成静态资源并版本化**，训练/评估/演示都用同一份。
13. **评估成本**：布点的效果只能通过下游（规划 + RL）测量，而下游跑一次很贵（回合长、随机性大）。

## 2. 训练方法（六种，按成本从低到高）

| # | 方法 | 需要的监督 | 优点 | 坑 |
|---|---|---|---|---|
| 1 | **解析教师 + 行为克隆（BC）** | 教师 = 膨胀自由空间的可见性图顶点（或 Dubins/RS 近最优路径的折点）；标签 = leave-one-out 边际贡献或使用频率 | 最便宜最稳，离线可无限并行 | 天花板就是教师（而教师本身是近似）；学不到教师没有的点 |
| 2 | **轨迹统计（不用训网络）** | 大量回合的轨迹（你的回放数据） | 极便宜；得到的点**天然行为相关** | 见第 4 节三个陷阱；需要一个对照策略 |
| 3 | **可微软 top-K + 端到端** | 目标 = 路径长度或下游回报 | 不需要教师；直接优化真目标 | 软硬选择有偏差，需退火；梯度噪声大 |
| 4 | **REINFORCE / 进化策略** | 奖励 = 集合评估（路径长度或任务回报） | 实现简单；能吃不可微目标 | 样本效率低；集合信用分配难 |
| 5 | **贪心边际增益（子模最大化）** | 无（纯算法） | 20 行代码，**强基线** | 不是学习，但**你必须跟它比**——学习版打不过它就没意义 |
| 6 | **逆最优控制 / IRL** | 专家示范（回放） | 最贴合你"看回放"的直觉，能反推代价函数 | 难度最高，收敛与可辨识性问题多 |

**建议的推进顺序**：`2（统计版）` → `5（贪心基线）` → `1（BC）` → 需要时再上 `3`。
**理由**：先用最便宜的方法确认"关键点这件事在你系统里有没有效果"，验证不过就**根本不要训网络**——这一步能省掉你几周。

## 3. 评估协议：如何证明"更有效"

### 核心难点

布点是中间件 → 效果必须通过下游测量；但下游测量混杂了**策略**与**随机性** → 必须做"只换图"的受控实验，并**在多个策略下重复**。

### L1 图级评估（便宜，快速迭代，**但不能下结论**）

- **帕累托曲线**：节点数 → 平均路径长度 / 参考最优（细网格 A* 或完整可见性图）；
- **连通性失败率**：随机 (起点,终点) 对里"无解"或"路径 > 2× 最优"的比例（**1.3 的坑会直接暴露在这里**）；
- **查询成本**：A* 扩展节点数、单次查询耗时、内存；
- **召回**：与解析教师节点集的重合度（若有教师）。

**这是一个"门槛"而不是结论**：如果学习版在节点数相同时路径长度还不如均匀采样图，**直接停**，不要浪费端到端算力。

### L2 端到端评估（唯一能下结论，但贵且有噪声）

**受控变量**：同一个 A*、同一份 RL 权重、同一批种子、同一场景集、同一判据。
**只换**：图 = ① 解析可见性图（上界）② 均匀采样图（**节点数必须相同**）③ 学习版。

两条必须遵守的规则：

1. **节点数必须是刚性约束**。节点多的图天然占优，节点数不同就没有可比性。
2. **必须交叉策略评估**：人工算法策略 + 学习策略各跑一遍（见第 4 节）。
3. **必须加一个"非自适应控制器"**（如纯跟踪 Pure Pursuit）作为**放大器**：自适应能力强的 RL 策略会**补偿**图的缺陷，把图的差异吃掉，导致你测不出差别。**用非自适应控制器才能放大图的差异**——这一步很多人漏掉，结果得出"图没影响"的错误结论。

### L3 先把"更有效"定义清楚（实验前写下来，三选一当主指标）

| 定义 | 主指标 |
|---|---|
| 几何效率 | 同成功率下路径更短 / **同路径质量下节点更少**（最贴合你的场景） |
| 任务效率 | 平均送达时间、吞吐、等待时间 |
| 战术效果（有炮台后） | 胜率、存活时间、被击中率（**路点正确性依赖对手策略 → 必须多对手评估**） |

### 一个残酷但必须接受的事实

**如果学习版的路径长度优势只有 2–3%，端到端很可能测不出来**（被策略的自适应和随机性吃掉）。这时正确结论是"**不值得上网络**"，而不是"再调调看"。所以在 L1 就要先确认优势足够大（经验上要 ≥10% 或节点数减少到 1/4 量级）。

## 4. 用"人工算法的对局回放"指导布点：三个陷阱

你的设想本身是对的方向（数据驱动、行为相关），但有三层陷阱：

### 陷阱 1：自证循环（最危险）

用人工算法的回放训练 → 又在人工算法下评估 → **必然更好**，因为图就是按它的轨迹定制的。
**必须交叉评估**：人工策略训练、学习策略评估（以及反过来）。**只在同一策略下闭环的结论是无效的。**

### 陷阱 2：回放只记录"走了哪"，没记录"为什么"

轨迹密集的位置可能是**必须经过**（真瓶颈），也可能只是**人工算法的偏好或缺陷**（比如它爱绕远路）。
**无法从单一轨迹集区分**。需要**对照**：与随机策略（或另一个策略）的轨迹对比，只保留"两者都离不开"的点——这就是 diverse density / 瓶颈检测那一脉的做法。

### 陷阱 3：路点价值依赖策略

学习策略可能学会走一条人工策略**从不经过**的捷径，而那里你没布点 → 评估时学习策略反而变差（图不支持它的路线）。
两种缓解：① 图里保留**覆盖性**约束（不能只挑高频点，要保证空间覆盖与连通）；② 把布点网络**条件化在策略上**——但那样每换一次策略就得重训，得不偿失。

### 结论：回放数据的正确用途

回放数据给你的是 **候选点与标签（L1 的输入）**，**不是有效性的证据**。有效性只能靠 **L2 的"只换图"受控重跑**得到。
一句话：**录像能告诉你"点该放哪"，不能告诉你"放得更好"。**

## 5. 建议的第一步（不训网络）

**先做轨迹统计版**，成本极低，而且它同时是标签来源和基线：

1. 用你现有的两个策略各跑 N 个回合，记录轨迹（你已经有日志设施）；
2. 计算**访问热力图**与**瓶颈指标**（宽度局部极小、介数中心性、轨迹熵低的区域）；
3. 构造"统计版"关键点集 → 走 L1 门槛（与均匀采样同节点数比较路径长度）；
4. 只有 L1 通过之后，才考虑训练网络去**逼近并泛化**这套统计布点。

**判定准则（什么时候值得上网络）**：
- 统计版/解析版已经够好 → **不要训网络**（省几周）；
- 需要**程序化地图**、**多车型**、或**战术路点（掩体/卡点/暴露）** → 才值得；
- 目标必须写成"更少的节点达到同等质量"或"自动生成替掉手工"，**不要写成"路径更短"**。
